==========================================
  RACHNA ELECTRICALS - SHOP MANAGER
==========================================

QUICK START
-----------

First time only:
  1. Make sure Python is installed. If not, get it from
     https://www.python.org/downloads/
     (During install, tick "Add Python to PATH")

  2. Double-click setup-windows.bat
     Wait 3-5 minutes. Close the black window when done.

Every day:
  1. Double-click shop-start.bat
  2. Wait 2-3 seconds for the browser to open.
  3. Use the app.
  4. When done, close the black window that says
     "Rachna Electricals - Running".


IMPORTANT NOTES
---------------

* Do NOT close the black window while using the app.
  If you close it, the app stops working.

* If the browser shows "This site can't be reached",
  wait 3-5 seconds and try refreshing.

* Do NOT open two copies of the app at once.
  If you can't start it because "Address already in use"
  appears, close the existing black window first.


THE DAILY BASICS
----------------

NEW SALE:
  Click the blue "New Sale" button at the bottom of the
  sidebar. It's the fastest way to record a sale.

NEW PURCHASE (from wholesaler):
  Sidebar -> Purchases -> "+ New Purchase" button.

PURCHASE LIST (things to order next time):
  Sidebar -> Purchase List.
  - Add items whenever you remember them.
  - When the order arrives, open a New Purchase, pick
    the wholesaler, click "Load from Purchase List",
    select items, and save.
  - Send the list to your wholesaler:
    "Copy list" button -> paste into WhatsApp.
    Or "CSV" button -> download for email/print.


CUSTOMERS WHO OWE YOU MONEY
---------------------------

Sales can be fully paid, partial, or unpaid.

For partial / unpaid sales, attach a customer (either
pick existing or "+ New"). The system tracks what they
owe.

To see who owes:
  Sidebar -> Customers.
  Click a customer -> see their full history.

When they pay:
  Open the customer's page -> "Record Payment" ->
  enter amount -> Save.


BACKUPS (VERY IMPORTANT)
------------------------

Your shop's entire data is saved in one file. Back it
up WEEKLY.

Click "Download Backup" at the bottom of the sidebar.
A file like "rachna-shop-backup-20261017-143022.db"
will download.

Save this file somewhere safe:
  - Email it to yourself
  - Drop it in Google Drive
  - Copy to a USB stick

If something goes wrong, your developer can restore
from the most recent backup.


IF SOMETHING BREAKS
-------------------

1. Close the black window.
2. Double-click shop-start.bat again.
3. If the browser still doesn't open, try typing
   http://localhost:8000 in the browser address bar.
4. If that fails, contact your developer.


WHAT'S INSIDE
-------------

* Products: your catalog, prices, stock levels
* Wholesalers: suppliers you buy from
* Purchases: bills from wholesalers
* Sales: every sale you've made
* Switchboards: pre-built boards with component costs
* Customers: people who owe you money
* Wholesaler Ledger: how much you owe each supplier
* Wholesaler Returns: stock you returned
* Purchase List: what to order next month
* Dashboard: today's numbers, monthly trends
