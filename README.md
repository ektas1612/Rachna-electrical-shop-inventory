# Rachna Electrical Shop Inventory

A local inventory and sales application for a small electrical retail shop.

## Current scope

- Flexible product categories
- Products with purchase and selling prices
- Purchase entries from wholesalers
- Sales entries
- Live inventory calculation
- Low-stock reminders
- Monthly sales reports

## Implemented features

- Project initialized with Git
- Static inventory dashboard layout
- Responsive dashboard CSS foundation
- FastAPI and SQLite backend setup
- Flexible category API
- Product API with category, unit, selling price, and reorder level


---

Product = what you sell
Purchase = stock coming in
Sale = stock going out
Available stock = total purchased − total sold
